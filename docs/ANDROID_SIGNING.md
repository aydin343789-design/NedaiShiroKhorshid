# تنظیم امضای ثابت برای به‌روزرسانی APK

برای اینکه نسخه‌های بعدی روی نسخهٔ قبلی نصب شوند، باید همهٔ APKهای قابل‌انتشار با **همان کلید خصوصی** امضا شوند. کلید امضا را هرگز در مخزن عمومی ذخیره نکنید.

در مخزن GitHub به مسیر **Settings → Secrets and variables → Actions → New repository secret** بروید و این چهار Secret را بسازید:

- `ANDROID_KEYSTORE_BASE64`: محتوای فایل keystore به‌شکل Base64
- `ANDROID_KEYSTORE_PASSWORD`: رمز keystore
- `ANDROID_KEY_ALIAS`: نام alias کلید
- `ANDROID_KEY_PASSWORD`: رمز کلید

پس از ثبت هر چهار Secret، workflow به‌جای امضای debug، نسخهٔ Release را با کلید ثابت می‌سازد. از این پس همهٔ نسخه‌ها باید با همین keystore امضا شوند؛ اگر آن را گم کنید، به‌روزرسانی مستقیم اپ نصب‌شده ممکن نخواهد بود.

## نکته دربارهٔ APKهای آزمایشی قدیمی

APKهای ساخته‌شده پیش از تنظیم این Secretها با کلید debug موقت Runner ساخته شده‌اند. چون کلید خصوصی آن Runner ذخیره نشده، نسخهٔ تازه با امضای ثابت روی آن APKها نصب مستقیم نمی‌شود؛ برای مهاجرت از آن نسخه‌ها یک بار حذف و نصب لازم است. بعد از مهاجرت به نسخهٔ Release امضاشده با کلید ثابت، به‌روزرسانی‌های بعدی باید بدون حذف برنامه انجام شوند، به شرط آنکه شناسهٔ بسته ثابت بماند و `versionCode` افزایش یابد.

مخزن عمومی نباید شامل فایل keystore، رمزها یا کلید API شخصی باشد.
