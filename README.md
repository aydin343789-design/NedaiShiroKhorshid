# ندای شیر و خورشید — نسخهٔ آزمایشی Piper

این شاخهٔ آزمایشی، ظاهر اصلی اپلیکیشن را حفظ می‌کند و موتور آفلاین Piper را از پروژهٔ ارسالی به آن وصل می‌کند.

## وضعیت موتورهای گفتار

- **Piper آفلاین:** مدل صدای انتخاب‌شده پس از دریافت روی گوشی نگهداری می‌شود و تولید صدا روی خود دستگاه انجام می‌شود. فایل پیوست سه مدل فارسی دارد: زنانه، مردانه و راوی؛ حجم هر مدل حدود ۶۱ مگابایت است و برای همان صدا فقط یک‌بار دریافت می‌شود. شخصیت کودک در نبود مدل کودکانهٔ جداگانه از مدل زنانه استفاده می‌کند.
- **Edge آنلاین:** کد فایل ارسالی به `msedge-tts` در Node.js نیاز دارد. آزمایش مستقیم در Cloudflare Workers به‌دلیل پشتیبانی‌نشدن `https.request`/`createConnection` موردنیاز `ws` شکست خورد؛ بنابراین این نسخه ادعای آنلاینِ کارکرده ندارد و دکمهٔ آنلاین فعلاً برای تولید صدا آماده نیست. برای فعال‌سازی آنلاین به runtime سروری سازگار یا API گفتار رسمی نیاز است.
- مدل‌های پیوست‌شده آفلاین فقط فارسی هستند. برای متن انگلیسی، این نسخه موتور آفلاین مناسبی ندارد.

## اجرا و ساخت

```bash
npm ci
npm run lint
npm run build
npm run android:sync
```

Push به شاخهٔ `test/piper-tts`، گردش‌کار Android را برای ساخت APK آزمایشی اجرا می‌کند. APK آزمایشی Debug است مگر اینکه کلید امضای Release به‌طور امن در تنظیمات GitHub مخزن اضافه شده باشد.

## منابع

تنظیمات صداها، مدل‌های Piper، موتور WebAssembly و پردازش متن از فایل ارسالی `اپلیکیشنمتنبهصدا.zip` گرفته شده‌اند. ظاهر و اجزای تصویری برنامهٔ ندای شیر و خورشید از خود مخزن باقی مانده‌اند.
