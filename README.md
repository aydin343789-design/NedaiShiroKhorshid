# ندای شیروخورشید

**ندای شیروخورشید** یک استودیوی فارسی برای تبدیل متن به گفتار است که دو مسیر مستقل دارد: موتور آنلاین آوا برای کیفیت بالاتر و موتور آفلاین Piper برای استفادهٔ بدون اینترنت. این پروژه برای ساخت فایل‌های صوتی از متن‌های فارسی، روایت داستان، تولید محتوای آموزشی، خوانش متن‌های ادبی، ساخت پیام‌های صوتی و استفاده در محیط‌هایی که حفظ حریم خصوصی اهمیت دارد، توسعه داده شده است.

در حالت آفلاین، متن و فایل صوتی در خود دستگاه پردازش می‌شوند. در حالت آنلاین، فقط متن برای تولید گفتار به Space عمومی Ava روی Hugging Face ارسال می‌شود و هیچ API پولی یا سرور متعلق به صاحب برنامه لازم نیست.

## قابلیت‌های اصلی

- تبدیل متن فارسی به گفتار با **مدل عصبی Piper TTS** و اجرای محلی با ONNX Runtime Web
- پشتیبانی از چهار شخصیت صوتی:
  - **سارا**: صدای زنانهٔ شفاف و رسا
  - **امیر**: صدای مردانهٔ گرم و باوقار
  - **کیان**: صدای کودکانهٔ پرانرژی
  - **راوی**: صدای عمیق و داستانی
- پشتیبانی از شش لحن خوانش:
  - شاد
  - صمیمی
  - غمگین
  - رسمی
  - حرفه‌ای
  - حماسی
- کنترل سرعت خوانش و زیر و بم صدا
- تولید فایل خروجی با فرمت MP3
- پخش، توقف، جابه‌جایی در فایل، بازپخش و دانلود فایل صوتی
- نگهداری تاریخچهٔ فایل‌های تولیدشده در حافظهٔ محلی دستگاه
- رابط کاربری فارسی و راست‌به‌چپ
- مناسب برای اجرا در مرورگر، WebView و نسخهٔ Android
- استفاده از لوگوی شیر و خورشید به‌عنوان آیکون رسمی برنامه و بستهٔ Android

## معماری صوتی

برای هر شخصیت و لحن، تنظیمات جداگانه‌ای برای مدل و پردازش صوت در نظر گرفته شده است. تفاوت لحن‌ها فقط با تغییر ظاهری سرعت یا زیر و بم ایجاد نمی‌شود؛ ریتم، مقیاس نویز مدل، گسترهٔ آوایی، رنگ طیفی و میزان فضای صوتی نیز متناسب با لحن تنظیم می‌شوند.

| شخصیت | مدل پایه | ویژگی صوتی |
|---|---|---|
| سارا | Mana Persian Piper | روشن، طبیعی و زنانه |
| امیر | Amir Persian Piper | گرم، بم و مردانه |
| کیان | Gyro Persian Piper | زیرتر، سریع‌تر و کودکانه |
| راوی | Amir Persian Piper | عمیق، آرام و روایی |

برای خوانش فارسی، متن پیش از ورود به مدل با نرمال‌سازی حروف عربی و فارسی، اصلاح فاصله‌ها، تبدیل اعداد و فرهنگ تلفظ واژه‌های مهم آماده می‌شود. علائم نگارشی نیز برای ایجاد مکث‌های طبیعی حفظ می‌شوند.

## اجرای آفلاین

در اولین استفاده از هر شخصیت آفلاین، فقط مدل همان شخصیت دانلود و در حافظهٔ Cache دستگاه ذخیره می‌شود. بعد از آن تولید گفتار، پردازش متن، ساخت MP3 و پخش صدا روی خود دستگاه انجام می‌شود.

فایل‌های runtime مورد نیاز نیز داخل پروژه قرار دارند:

- ONNX Runtime Web
- Piper phonemizer WebAssembly
- داده‌های eSpeak برای آوانگاری فارسی

بنابراین متن کاربران به هیچ سروری ارسال نمی‌شود.

## ساخت نسخهٔ Android

پروژه با Capacitor برای ساخت APK آماده شده است. در سیستمی که Android SDK و Java 21 نصب شده باشد، می‌توان پوستهٔ Android را ساخته و APK را تولید کرد:

```bash
npm run android:apk
```

این فرمان ابتدا نسخهٔ وب را می‌سازد، در صورت نبودن پوشهٔ Android پوستهٔ لازم را ایجاد می‌کند، فایل‌های وب را همگام‌سازی می‌کند و سپس APK را می‌سازد.

لوگوی موجود در `resources/icon.png` هنگام ساخت Android به آیکون‌های launcher در تمام تراکم‌های صفحه تبدیل می‌شود و روی بستهٔ APK و صفحهٔ برنامهٔ گوشی نمایش داده خواهد شد.

## ساخت خودکار APK در GitHub Actions

با هر Push روی شاخهٔ `main`، گردش‌کار زیر اجرا می‌شود:

1. نصب Node.js و Java 21
2. نصب Android SDK، platform-tools، Android API 35 و build-tools
3. نصب وابستگی‌های پروژه
4. بررسی TypeScript
5. ساخت نسخهٔ production وب
6. ساخت و همگام‌سازی پروژهٔ Capacitor Android
7. تولید APK نسخهٔ Debug
8. بارگذاری APK به‌عنوان Artifact

فایل APK در Artifact با نام **Nedaye-Shirokhorshid-apk** قرار می‌گیرد. اگر keystore خصوصی در Secrets تنظیم نشده باشد، خروجی Debug است؛ در غیر این صورت Release امضاشده ساخته می‌شود.

## اجرای روی گوشی‌های اندرویدی

APK نسخهٔ Debug برای دستگاه‌های معمول Android ساخته می‌شود و برای گوشی‌هایی مانند **Samsung Galaxy A04 با حافظهٔ ۶۴ گیگابایت** قابل استفاده است. برای اجرای صحیح، فضای خالی کافی برای مدل صوتی انتخاب‌شده لازم است؛ مدل‌های صوتی به‌صورت تنبل (on-demand) دانلود و سپس محلی نگهداری می‌شوند.

## ساختار مهم پروژه

```text
src/
├── App.tsx                         رابط اصلی برنامه
├── components/                     پخش‌کننده و اجزای رابط کاربری
├── data/                           شخصیت‌ها، لحن‌ها و متن‌های فارسی
├── utils/neuralPersianTts.ts       موتور عصبی آفلاین و کش مدل‌ها
├── utils/persianNormalizer.ts      نرمال‌سازی و آماده‌سازی متن فارسی
└── vendor/piperPhonemize.js        آوانگاری Piper با WebAssembly

public/runtime/
├── ort/                            فایل‌های ONNX Runtime WebAssembly
└── piper/                          فایل‌های Piper phonemizer

resources/icon.png                  لوگوی رسمی launcher و بستهٔ Android

.github/workflows/android-apk.yml   گردش‌کار ساخت خودکار APK
capacitor.config.json               تنظیمات بستهٔ Android
scripts/sync-android.mjs            ساخت و همگام‌سازی پروژهٔ Android
```

هدف من از توسعهٔ ندای شیروخورشید، فراهم‌کردن یک ابزار فارسی، خصوصی، سریع و قابل استفاده روی دستگاه برای تولید صدای طبیعی است؛ ابزاری که بدون وابستگی دائمی به اینترنت کار کند و برای تولید محتوای صوتی فارسی، روایت، آموزش و استفادهٔ روزمره در دسترس باشد.

## موتور آنلاین رایگان + حالت آفلاین

نسخهٔ جدید برنامه دو مسیر مستقل برای تولید گفتار دارد:

- **آنلاین · آوا**: از Ava Persian TTS روی Hugging Face Space استفاده می‌کند. این مسیر به API Key، حساب پولی یا سرور متعلق به صاحب برنامه نیاز ندارد و برای تولید صدا اینترنت لازم دارد. Ava یک مدل فارسی 82M پارامتری است و با مجوز Apache-2.0 منتشر شده است.
- **آفلاین · Piper**: همچنان روی خود دستگاه و با ONNX Runtime Web اجرا می‌شود. هیچ متن یا فایل صوتی در این حالت به سرور ارسال نمی‌شود.

برای جلوگیری از بزرگ‌شدن APK، مدل Ava داخل برنامه بسته‌بندی نشده است. همچنین در حالت آفلاین دیگر همهٔ مدل‌ها در اولین اجرا دانلود نمی‌شوند؛ فقط مدل موردنیاز شخصیت انتخاب‌شده دریافت و در Cache محلی نگهداری می‌شود.

> نکته: موتور آنلاین یک سرویس عمومی رایگان شخص ثالث است؛ بنابراین در صورت خواب‌بودن Space، قطعی اینترنت یا تغییر سرویس ممکن است موقتاً در دسترس نباشد. برنامه در این شرایط کاربر را به حالت آفلاین هدایت می‌کند.
