# ندای شیروخورشید

استودیوی فارسیِ تبدیل متن به گفتار با اجرای **واقعاً محلی** در مرورگر یا WebView اندروید. متن کاربر و فایل صوتی هرگز به سرور TTS ارسال نمی‌شوند.

## آنچه اصلاح شده است

- **موتور عصبی Piper درون‌برنامه‌ای** جایگزین مسیر معیوب سرور و صدای مصنوعی مرورگر شده است.
- سه مدل فارسیِ Piper (مانا، امیر و گیرو) در اجرای اول دریافت و در Cache Storage دستگاه ذخیره می‌شوند؛ اجرای‌های بعدی **بدون اینترنت** هستند.
- فایل‌های مورد نیاز اجرای مدل (ONNX Runtime، phonemizer و دادهٔ eSpeak) داخل برنامه قرار دارند؛ پس فقط مدل‌های صدا در اجرای نخست دانلود می‌شوند.
- چهار شخصیت از پروفایل‌های مدل، سرعت طبیعی، رنگ صوتی و زیروبم متفاوت استفاده می‌کنند.
- شش لحن شاد، صمیمی، غمگین، رسمی، حرفه‌ای و حماسی اکنون پارامترهای جداگانهٔ Piper (ریتم، پویایی و گسترهٔ آوایی) و پردازش طیفی کنترل‌شده دارند.
- پخش هم‌زمان Web Speech API حذف شده است. آن پخش دوگانه علت اصلی صدای مصنوعی و درهم‌ریختهٔ نسخهٔ قبل بود.
- خروجی واقعی MP3 به‌صورت محلی ساخته می‌شود.

> کیفیت گفتار به مدل‌های عصبی محلی و توان پردازشی دستگاه وابسته است. برای بهترین نتیجه، متن فارسی را با علائم نگارشی و جمله‌های کامل وارد کنید.

## اجرای محلی

```bash
npm ci
npm run dev
```

برای ساخت نسخهٔ وب:

```bash
npm run build
```

## ساخت APK اندروید

پوشش Capacitor و گردش‌کار GitHub Actions در مخزن آماده است. با هر Push روی شاخهٔ `main`، گردش‌کار **Build Android APK** اجرا می‌شود و فایل `Nedaye-Shirokhorshid-debug-apk` را به‌عنوان Artifact منتشر می‌کند.

برای ساخت محلی در سیستمی که Android SDK دارد:

```bash
npm run android:apk
```

این فرمان پوستهٔ Android را در صورت نیاز می‌سازد؛ متغیر `ANDROID_HOME` باید به Android SDK معتبر اشاره کند.

در اجرای اول برنامه، نوار وضعیت دانلود مدل‌ها را نمایش می‌دهد. پس از نمایش «کاملاً آفلاین»، می‌توان اینترنت را قطع کرد و همچنان گفتار ساخت.

## معماری آفلاین

| بخش | محل اجرا | وضعیت اینترنت |
|---|---|---|
| رابط کاربری و فایل‌های runtime | داخل APK / مرورگر | آفلاین |
| دانلود اولیه مدل‌های فارسی | فقط اجرای اول | نیازمند اینترنت |
| کش مدل‌ها | Cache Storage دستگاه | ماندگار و آفلاین |
| phonemization و ONNX inference | روی دستگاه | آفلاین |
| ساخت و پخش MP3 | روی دستگاه | آفلاین |
